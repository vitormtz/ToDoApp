# Lista de Tarefas (ToDoApp)

Este é um aplicativo simples de lista de tarefas desenvolvido com HTML, CSS e JavaScript puro. O aplicativo permite que os usuários gerenciem suas tarefas diárias com funcionalidades básicas de CRUD (Create, Read, Update, Delete) e persistência de dados usando localStorage.

## 📋 Funcionalidades

- **Adicionar Tarefas:** Insira novas tarefas através do campo de texto
- **Visualizar Tarefas:** Lista todas as tarefas adicionadas
- **Editar Tarefas:** Permite modificar o texto de tarefas existentes
- **Excluir Tarefas:** Remove tarefas da lista
- **Persistência de Dados:** As tarefas são salvas no localStorage do navegador
- **Interface Responsiva:** Design adaptável para diferentes tamanhos de tela

## 🛠️ Tecnologias Utilizadas

- **HTML:** Estruturação da página
- **CSS:** Estilização e animações
- **JavaScript:** Lógica e interatividade
- **Bootstrap:** Framework de CSS para estilização
- **localStorage:** Armazenamento local dos dados

## 🚀 Como Executar o Projeto

1. Clone este repositório ou baixe os arquivos
2. Certifique-se de que todos os arquivos estejam na mesma pasta
3. Abra o arquivo `index.html` em um servidor web
   - **Importante:** Devido ao uso do localStorage, é necessário abrir o arquivo através de um servidor web (não funciona abrindo o arquivo diretamente)
   - Você pode usar extensões como "Live Server" do VS Code ou qualquer servidor web local
